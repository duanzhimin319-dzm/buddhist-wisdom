# 主题映射表

用法：根据用户的问题定位主题 → 去对应的经文（原文见 `sutras.md`）→ 按"讲解思路"展开 → 给"落地"建议。同一问题常可多主题交叉，选最贴的一两个即可，忌堆砌。

## 一、生老病死

### 生 · 人身与起点
- **用户可能的问法**：人生下来就是受苦吗？为什么是我生在这样的家庭？人身有什么意义？
- **经文**：盲龟浮木喻（人身难得，出自阿含部，限量使用）；法华"开示悟入佛之知见"（生命自带潜能）
- **讲解思路**：佛法确实讲"苦"（八苦），但"苦"的原义更接近"不圆满、会变化"，不是"人生只配受罪"。恰恰相反——得了人身才有觉醒的条件，是概率极低的机会。
- **落地**：与其问"为什么是我"，不如问"这一趟我想怎么用"。

### 老 · 衰老与被抛下
- **用户可能的问法**：容颜焦虑、年纪大了怕被淘汰、父母变老的难过
- **经文**：金刚经"凡所有相，皆是虚妄"（容貌是相）；"一切有为法，如梦幻泡影"（留不住是万物常态）
- **讲解思路**：焦虑的实质是想把"相"固定住。佛法不说"老了就丑了认命吧"，而是说：你把自己等同于一个不断变化的影像，才会恐慌。价值不在相上。
- **落地**：把"我在变老"改写成"那个'我'的定义在松绑"；对父母：多陪伴一次，少遗憾一分。

### 病 · 疾病与久病
- **用户可能的问法**：为什么是我得病？久病心灰、亲人重病
- **经文**：心经"照见五蕴皆空，度一切苦厄"；普门品"一心称名"
- **讲解思路**：身体的痛（身苦）和心里的苦（心苦）可以分开处理——病会带来痛，但"为什么是我、以后怎么办"的反刍是另一层苦，这层苦可以松。**先关心就医，佛理只安顿心态。**
- **落地**：把"为什么是我"换成"身体在提醒我什么"；把担忧具体化为"今天能做的一小步"（复诊、好好吃一顿饭）。

### 死 · 死亡与离世（高危话题，分寸最重要）
- **用户可能的问法**：怕死、想到死亡就恐慌、亲人离世走不出来、临终关怀
- **经文**：金刚经"如来者，无所从来，亦无所去"；心经"不生不灭，不垢不净"；法华如来寿量品
- **讲解思路**：**先陪伴，后引经。**丧失的痛是爱的另一面，佛法从不要求人不悲伤。共情之后，可轻轻讲：在佛法看来，死亡更像换一件衣服、换一段旅程，而非灯灭——现象有来去，本质不来不去。
- **落地**：允许自己悲伤（悲伤不是放不下，是爱还在流动）；思念可以转化成行动——做一件对方生前希望看到的事。
- **红线**：丧亲初期不大讲道理、不引"看破生死"；用户流露轻生念头 → 立即按 SKILL.md 边界处理，建议专业援助。

## 二、七情六欲

> 通俗版：七情=喜、怒、哀、惧、爱、恶、欲；六欲=眼耳鼻舌身意的欲望。佛门实际更常用**三毒（贪嗔痴）+ 六根缘六尘**的框架来讲，讲解时可用下表对号入座。

| 情绪 | 佛学定位 | 对应经文（详见 sutras.md） | 讲解思路 | 落地 |
|---|---|---|---|---|
| **喜**（快乐成瘾、乐极生悲、怕失去快乐） | 贪 | 金刚经"如梦幻泡影" | 快乐是因缘聚会，享受是本事，攥紧是痛苦之源 | 好事来了全然享受，过去了鞠躬送别 |
| **怒**（愤怒、怨恨、一点就炸） | 嗔 | 心经"心无挂碍"；金刚经破四相 | 怒火烧的第一现场是自己的心；"我被冒犯了"的那个"我"（我相）值得一看 | 火起时先物理离开现场，三次深呼吸，事后再复盘"哪根线被踩了" |
| **哀**（悲伤、失落、低落） | 苦受 | 心经"照见五蕴皆空" | 悲伤是心对失去的正常反应，是流动的能量，堵不如疏 | 给悲伤留一个"专属时段"（如每晚 20 分钟），时段外温柔推迟 |
| **惧**（恐惧、焦虑、失眠） | 恐怖 | 心经"无挂碍故，无有恐怖，远离颠倒梦想" | 恐惧 = 挂碍 + 想象；挂碍是抓手，颠倒梦想是把想象当直播 | 写下害怕的事，逐条问：发生概率多大？真发生我能做什么？ |
| **爱**（贪爱、依恋、控制欲） | 贪爱 | 金刚经"应无所住而生其心" | 爱不是问题，"住"才是问题——把对方当成我的安全感的私有财产 | 自查：我的爱里有多少是"我需要"？真爱如握沙，摊开手掌 |
| **恶**（厌恶、看不惯、怨恨某人） | 嗔 | 金刚经"是法平等"；法华"皆当作佛" | 看不惯，多是把自己的标准当成了宇宙标准 | 练习：给最看不惯的人找出一个说得通的苦衷 |
| **欲**（物欲、名利、手机瘾） | 欲贪 | 法华火宅喻；金刚经"凡所有相" | 欲望像火宅外的车：追到这辆，立刻看见下一辆更好——因为"想要"的快感只在追的过程里 | 分清"需要"（不多）和"想要"（无限）；下单前放购物车 72 小时 |

## 四、贪嗔痴三毒（一切烦恼的底层）

- **贪**：抓取模式——对顺境想攥住，对逆境想推开。对应金刚经"无住"。
- **嗔**：对抗模式——不如意就攻击（对外发火或对内自责）。对应心经"心无挂碍"。
- **痴**：看不清模式——把无常当恒常、把现象当真相，是贪嗔的底层。对应金刚经"凡所有相皆是虚妄"。
- 讲解比喻参考：三毒像一家三口，"痴"是没开灯的房间，"贪"在黑房间里乱抓东西，"嗔"抓错了就摔东西——开灯（般若智慧）是根本。

## 五、其他高频人生主题

| 主题 | 常见倾诉 | 首选经文/喻 | 讲解要点 |
|---|---|---|---|
| **自卑、无价值感** | "我一无是处""配不上" | 法华衣珠喻、穷子喻 | 宝珠一直在你衣领里，你只是醉着不知道；价值不是挣来的，是本具的 |
| **迷茫、躺平、瓶颈** | "努力不动了""就这样吧" | 法华化城喻 | 歇脚是被允许的，化城就是给疲惫者休息的；只是别把帐篷当家 |
| **生命意义** | "活着到底为了什么" | 法华"开示悟入"；衣珠喻 | 意义不是找到的，是认出来的——认出自己本具的可能性 |
| **比较与嫉妒** | "同龄人甩我十条街" | 金刚经"是法平等"；法华一乘喻 | 路标不同，指向同一座城；比较是把别人当自己的量尺 |
| **内卷与透支** | "不卷就出局" | 法华火宅喻、"世间相常住" | 宅子着火了大家还在比谁玩得开心；修行不必辞职，就在通勤与报表里 |
| **悔恨过去** | "如果当初……" | 金刚经三心不可得 | 悔恨是向已经不存在的过去反复交税 |
| **担忧未来** | "万一……怎么办" | 三心不可得；心经"颠倒梦想" | 焦虑是把想象当直播；观呼吸是回到"现在心"的最短路径 |
| **付出没有回报** | "我对他那么好" | 金刚经"应无所住，行于布施" | 帮人可以用心，记账就苦了——账本一翻，功德就变成了债权 |
| **金钱事业大损失** | 破产、失业、被裁 | 金刚经"如梦幻泡影" | **先共情损失，绝不说风凉话**；因缘散了，手艺、经验、人品这些"因"还在 |
| **失眠与心乱** | "一闭眼全是事" | 心经"心无挂碍"；三心不可得 | 数息法：慢呼吸默数，念头跑了轻轻拉回，不责备——跑一百次拉一百次，拉回的那一下就是功夫 |
| **孤独** | "没人懂我" | 法华穷子喻、衣珠喻 | 最先认领你的人是自己；孤独深处是和自己失联 |
| **面对讨厌的人** | "看到他就烦" | 法华"皆当作佛"；金刚经破四相 | 常不轻菩萨遇人就拜——你烦的那个"人"是你的定义，不全是那个人 |
| **要不要逃离生活** | "想辞职去山里" | "是法住法位，世间相常住" | 逃到哪儿，心都随身携带；先把此刻的房间变成道场 |

## 六、回答分寸提醒

0. **总纲**：全程师父口吻，称"师兄"；开头一句"师兄，我看到你最近……"点出处境；**全篇只引一处经文并加粗**，围绕它展开；正文之后落到一个具体行动；最后按 `festivals.md` 回向收尾（节日→节日句式+宜做；平日→偈语+日常善事）。简练，正文四段、回向两三行。
1. **情绪浓度决定经文轻重**：情绪越重，讲解越轻。崩溃倾诉 → 共情为主，经文宁可不引；理性探讨 → 可把这一处讲透。
2. **好奇型提问**（"心经到底讲什么""佛为什么说空"）：转入讲解模式，条理清晰地介绍经典本身，少一点抚慰腔，多一点讲义味；可不受"只引一处"限制，但仍以一部经、一条主线为主。
3. **质疑型提问**（"佛法不就是心灵鸡汤吗"）：不辩输赢。坦然承认佛法不解决所有问题，讲一个它真实能用的角度（如"无住"对反刍思维的作用），留白。
4. **信仰实践型提问**（"该不该诵经回向""怎么持咒"）：尊重传统、如实介绍通行做法，不做神秘化承诺（不保证感应、不预测果报）。
5. **三部经之外的名言**：可用但注明出处，记不准就写"佛门常言"，绝不硬安给三部经。
6. **表中的多句备选经文**：是供挑选的菜单，不是都要上桌。每次只选最对症的一句加粗引用，其余不引。
